# グラス点字 — Glass Tenji

Meta Ray-Ban Display 用の**点字学習アプリ**。日本語のかな点字（清音46字・濁音／半濁音25字・拗音33字・数字10字・記号4種）を、D-padで五十音表をたどりながら大きな6点セルで確認できる。選んだ文字には「か行 ＝ あ行の形 ＋ ⑥」「濁音 ＝ 前に ⑤」のように**点字のしくみ**が一言で出るので、丸暗記ではなく規則で覚えられる。4択クイズ（清音／濁音・拗音・数字の2コース）で定着度チェック。タップとD-padだけで完結・依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-tenji.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / DOM / 静的サイト）

## 特徴

- **五十音表をD-padでたどる** — ←→で行（あ・か・さ…）、↑↓で段（あ・い・う…）。選んだ文字の点字が左に大きく表示され、タップすると点が①→②→…の順にポップして浮き上がる
- **しくみが分かるヒント** — 母音（あいうえお）の形を基本に、か行は＋⑥、さ行は＋⑤⑥、た行は＋③⑤…と加える点で覚えられる。数字は数符③④⑤⑥のあとに「あ・い・う・る・ら・え・れ・り・お・ろ」の形、という対応も表示
- **4つのページ** — 清音（ゐ・ゑ・ん・っ・ー含む）／濁音・半濁音／拗音・拗濁音・拗半濁音／数字・記号（。、？！・空マス）。上のタブ列に↑で移動して←→で切りかえ
- **4択クイズ** — 点字を見てかなを答える10問。まぎらわしい同じ行・同じ段の文字が選択肢に混ざる。正解時はそのしくみを一言で復習、不正解時は正解を表示。ベストスコアを localStorage に保存
- **加算式ディスプレイ向けの表示** — 純黒の背景は透明。打つ点は白＋金のグローで大きく、打たない点は暗い輪郭だけ

## 操作方法

| 画面 | 操作 |
|------|------|
| メニュー | ↑↓で「五十音表をみる／クイズ：清音／クイズ：濁音・拗音・数字」をえらび、タップで決定 |
| 五十音表 | ←→＝行を移動、↑↓＝段を移動、タップ＝点を浮かせるアニメ。一番上の段で↑を押すとタブ列へ |
| タブ列 | ←→＝ページ（清音／濁音／拗音／数字・記号／もどる）を切りかえ、タップ＝そのページの表へ（「もどる」でメニューへ）、↓＝表へもどる |
| クイズ | ←→↑↓で4択をえらび、タップで答える。10問終わると結果画面 |
| 結果 | ↑↓で「もういちど／五十音表をみる／メニューへ」をえらび、タップで決定 |
| PC確認用 | Escape でメニューへ、クリックでメニュー・タブ・表のマス・選択肢を直接選択（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けるとベストスコアを保存・復元しません（デモ録画用）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E7%82%B9%E5%AD%97&appUrl=https%3A%2F%2Fglass-tenji.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス点字`、URL `https://glass-tenji.vercel.app` を入力。
